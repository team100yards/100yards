# How to publish this on team100yards.github.io/100yards

1. Go to your repo `team100yards/100yards` on GitHub.
2. Upload these files (`Add file → Upload files`, drag them in):
   `index.html`, `academy.html`, `team.html`, `resources.html`,
   `contact.html`, `styles.css`, `script.js`, `config.js`,
   `logo.png`, `pitch-bg.svg`.
3. Choose "Replace" when it asks about files that already exist —
   this overwrites the old versions.
4. Commit directly to your default branch (usually `main`).
5. Wait 1–2 minutes, then reload
   https://team100yards.github.io/100yards/index.html (hard refresh /
   clear cache if you still see the old version).

## Changing the Team page link later
Whenever your team-management link changes, you only need to touch
ONE file — `config.js`:
1. Open `config.js` in your repo → click the pencil icon (Edit).
2. Replace the link between the quotes with your new one.
3. Commit. The Team page updates automatically — no other file
   needs to change.
