# How to publish this on team100yards.github.io/100yards

1. Go to your repo `team100yards/100yards` on GitHub.
2. Upload these files (`Add file → Upload files`, drag them in):
   `index.html`, `academy.html`, `resources.html`, `contact.html`,
   `styles.css`, `script.js`, `logo.png`, `pitch-bg.svg`.
3. Choose "Replace" when it asks about files that already exist —
   this overwrites the old versions.
4. Commit directly to your default branch (usually `main`).
5. Delete the old `100 yards logo.png` file from the repo (right-click
   it → Delete file) — it's no longer used, the new crest is `logo.png`.
6. Wait 1–2 minutes, then reload
   https://team100yards.github.io/100yards/index.html (hard refresh /
   clear cache if you still see the old version).

Nothing else in your repo needs to change.
